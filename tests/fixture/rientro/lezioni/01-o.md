## Batti
```js
function f() {
    return 1;
}
console.log(f());
```

### Blocchi
1-3: La funzione | f restituisce 1. | Una funzione minima.
4-4: La chiamata | Stampa quello che restituisce f. | Ora la usi.

### Suggerimenti
1: function apre la funzione f.
2: return restituisce 1.
3: La graffa chiude la funzione.
4: Chiama f e stampa il risultato.

## Modifica
consegna: Aggiungi una riga dentro la funzione.
aiuto: ‹o› apre una riga sotto: il rientro lo scrivi tu.
motivo: Prova che il rientro non arriva da solo.
par: 9
soluzione: o<Tab>let x;<Esc>
mostra: o · Tab · let x; · Esc
```js
function f() {
    let x;
    return 1;
}
console.log(f());
```
